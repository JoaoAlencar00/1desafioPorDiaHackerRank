# Plano de prática de Java no HackerRank

Repositório criado para organizar uma proposta de estudo: resolver um desafio por dia no [HackerRank](https://www.hackerrank.com/) e registrar o aprendizado em Java.

## Objetivos

- Praticar lógica de programação.
- Fortalecer o raciocínio com algoritmos e estruturas de dados.
- Acompanhar a evolução na linguagem por meio de exercícios.

## Estado do repositório

A versão publicada contém apenas este README. Ainda não há soluções Java, enunciados, instruções de execução ou testes no repositório.

A frequência de um desafio por dia representa o objetivo de estudo, e não um registro de desafios já concluídos.

## Organização sugerida para os próximos registros

Cada exercício pode incluir o link para o enunciado original, o código da solução, uma explicação da abordagem e exemplos de entrada e saída. A estrutura sugerida facilita documentar as soluções à medida que forem desenvolvidas.

## Referência

Plataforma de prática: [HackerRank](https://www.hackerrank.com/). Os enunciados e suas atribuições pertencem às respectivas fontes.
